Data Entry / Slider

Slider 滑块

滑块用于在连续或分段范围内选择数值，适合阈值、比例、预算、权重和进度控制。企业应用 平台的滑块应保持轨道轻量、控制点清晰；更多用法可承载刻度、提示气泡，并在需要精确值时与数字输入框联动。

  • 默认范围 0-100
  • 默认步长 1
  • 支持单值与范围选择
  • Hover / Focus 使用 3px focus shadow
  • 数字输入框联动宽度 80px

何时使用

  • 用于调整成功率阈值、资源占比、预算比例、优先级权重等有明确上下限的数值。
  • 需要用户快速感知范围和当前位置时优先使用滑块；需要精确录入时搭配 80px 数字输入框。
  • 可枚举档位少且语义明确时，在更多用法中使用 marks；只能选择档位时开启 onlyMarkValue。
  • 连续数值不要放置过密刻度，避免轨道噪声过高。
  • 范围选择用于表达上下限、时间窗口、价格区间等双端约束。

状态

Default

默认状态只显示轨道、选中段和控制点。

Hover

悬停时仅当前圆形控制点放大，并显示 3px 绿色 focus shadow；范围滑块两侧互不影响。

Focus

键盘聚焦时仅当前控制点显示 3px 绿色 focus shadow，拖动释放后恢复默认状态。

Disabled

禁用态降低轨道与控制点对比度，不响应拖拽；圆形控制点 hover 时仅显示浅灰 shadow。

尺寸与方向

Size

默认尺寸用于表单区域；紧凑工具栏可降低轨道和控制点尺寸，重点配置可放大。

Vertical

垂直滑块用于空间受限的参数面板，标签应放在旁侧说明区域。

API

属性 说明 类型 默认值
value 当前值，单值模式为 number，范围模式为 number[]。 number | number[] -
defaultValue 非受控默认值。 number | number[] -
min 滑动范围最小值。 number 0
max 滑动范围最大值。 number 100
step 每次滑动的步长。 number 1
range 是否启用范围选择；可配置范围轨道是否可拖拽。 boolean | { draggableBar: boolean } false
marks 刻度标签，key 必须在 min 和 max 范围内。 Record<number, ReactNode> -
showTicks 是否显示步长刻度线。 boolean false
onlyMarkValue 只能选择 marks 中的值，此时 step 会被忽略。 boolean false
showInput 是否展示右侧数字输入框。设计规范中使用 InputNumber 结构，默认整体宽度 80px，步进器宽度 28px；onlyMarkValue 或范围多点选择时隐藏。 boolean | InputNumberProps | InputNumberProps[] false
tooltipVisible 控制 Tooltip 展示，true 常显，false 始终隐藏。 boolean -
tooltipPosition Tooltip 展示位置。 top | bottom | left | right | tl | tr | bl | br | lt | lb | rt | rb top
formatTooltip 格式化 Tooltip 内容，例如补充百分比、单位或业务阈值说明。 (value: number) => string | ReactNode -
vertical 是否使用垂直方向。 boolean false
reverse 是否反向坐标轴。 boolean false
disabled 禁用滑块，不响应点击、拖拽和键盘操作；圆形控制点 hover 时使用浅灰 shadow，不放大。 boolean false
interactionState 用于静态规范或受控演示的交互态；hover、focus 仅作用于当前圆形控制点，拖动释放后恢复 default。 default | hover | focus | disabled default
onChange 选择值变化时触发。 (value: number | number[]) => void -
onAfterChange 鼠标或拖拽释放后触发，用于提交最终值。 (value: number | number[]) => void -
