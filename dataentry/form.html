Data Entry / Form

Form 表单

表单用于收集、校验并提交结构化任务配置。企业应用平台中常用于创建 Agent、 配置自动化任务、编辑店铺资料和批量操作参数，布局应保持字段关系清晰，并支持控件联动、 动态增减、键盘流转与贴近字段的校验反馈。

  • 默认控件高度 38px
  • 标签宽度 96px
  • 字段间距 18px
  • 行内按钮 32px 居中对齐
  • 支持联动、动态项与校验

何时使用

  • 用于需要用户输入多个字段并统一提交的场景，例如创建任务、编辑策略、配置 Agent。
  • 字段之间存在明确依赖或校验规则时，使用表单承载状态、帮助信息和错误反馈。
  • 可变数量的参数、取值或规则应使用动态表单项，并明确最小/最大数量与键盘流转顺序。
  • 行内筛选区域的查询按钮保持 32px 高度，并与 38px 选择器触发器视觉居中对齐。
  • 简单开关或单一即时操作不应放入完整表单，可直接使用 Switch、Checkbox 或 Button。
  • 错误信息应放在对应字段下方，避免只在页面顶部或 toast 中说明。

表单校验

实时字段校验

输入变化时同步字段状态，错误信息贴近控件展示，修正后立即恢复成功反馈。

提交校验

点击提交后批量校验必填、格式和数值范围，错误信息贴近对应字段展示。

状态

Default / Focus

默认使用轻边框；聚焦时使用品牌绿描边和外发光。

Error / Success / Disabled

校验状态跟随字段展示；禁用态保持可读但不可编辑。

API

属性 说明 类型 默认值
layout 表单布局方式。 horizontal | vertical | inline horizontal
labelWidth 水平布局标签宽度，用于保持字段起始线对齐。 number | string 96
required 是否展示必填标识。 boolean false
status 字段校验状态。 error | success | warning -
interactionState 用于静态规范或受控演示的交互态；hover 仅使用品牌绿边框，不出现外发光。 default | hover | focus default
help 字段下方的帮助或错误文案。 string -
disabled 是否禁用表单或单个字段。 boolean false
dependencies 字段联动关系。前置字段变化后，可过滤后续选项、重置默认值或启停相关字段。 FormDependency[] []
dynamicItems 动态表单项数据源，支持单值列表和键值对列表。 Array<string> | Array<{ key: string; value: string }> []
minItems 动态表单项最小保留数量，达到下限时删除按钮禁用。 number 0
maxItems 动态表单项最大数量，达到上限时新增按钮禁用。 number -
keyboardOrder 动态项键盘流转策略。动态参数值按编号聚焦到每个输入项，最后聚焦新增按钮。 natural | input-first natural
rules 字段校验规则，支持必填、URL 格式和数值范围等规则。 FormRule[] []
validateTrigger 校验触发时机，可用于实时字段校验或提交时批量校验。 input | blur | submit submit
onValuesChange 字段值变化时触发，常用于联动更新、动态项同步和实时校验。 (values) => void -
