Data Entry / Mentions

Mentions 提及

提及用于在文本输入中快速引用成员、Agent、任务标签或命令。企业应用平台中常用于任务说明和协作备注， 用户输入触发符后通过浮层候选列表插入对象，插入后的对象以绿色 token 高亮展示。

  • 默认触发符 @
  • 支持 @ # / 触发符
  • 候选菜单浮层展示
  • 支持清除

何时使用

  • 用于在一段可编辑文本里插入结构化对象，例如成员、Agent、任务标签、命令或团队频道。
  • 候选项需要跟随触发符和关键词动态筛选时使用 Mentions；只需要独立字段选择时优先使用 Select 或 AutoComplete。
  • 下拉菜单应作为浮层展示，不占用底层页面高度；候选项保持单行纯文本，避免前置缩写和副标题干扰选择效率。
  • 提及项插入后应保留普通文本编辑能力，选中项与后续文字之间通过 split 形成清晰分隔。

基础用法

占位提示

空内容时展示明确提示，引导用户用默认触发符插入对象。

输入 @ 提及 Agent 或团队成员

触发与筛选

自定义触发字符

通过 prefix 支持 @、#、/ 等多种触发符，对应不同候选集合。

输入 @、# 或 / 触发不同候选
  • #Listing
  • #Ads

无匹配结果

候选项为空时使用 notFoundContent 给出轻量反馈。

输入 @unknown 查看无匹配状态
  • 暂无匹配对象

设计 Token

Token 值 用途
--mentions-width 360px 默认输入框宽度。
--mentions-height-small 30px Small 尺寸输入框高度。
--mentions-height 38px 默认输入框高度。
--mentions-height-large 44px Large 尺寸输入框高度。
--mentions-border-color #DDE1E5 默认边框颜色。
--mentions-radius 10px 输入区圆角。
--mentions-menu-width 260px 候选菜单默认宽度；菜单作为浮层展示，不影响页面高度。
--mentions-menu-radius 8px 候选菜单圆角。
--mentions-option-height 36px 候选项最小高度；候选项为单行纯文本。
--mentions-menu-z-index 10 候选菜单浮层层级。
--mentions-token-bg rgba(0, 209, 87, 0.1) 已插入提及 token 背景。
--mentions-clear-size 18px 清除按钮尺寸，与 Select 清除按钮一致。
--mentions-focus-shadow 0 0 0 3px rgba(0, 209, 87, 0.16) 聚焦与展开外发光。
