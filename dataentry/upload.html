Data Entry / Upload

Upload 上传

上传用于在 Agent 对话、任务创建和任务详情中提交素材、配置包和执行附件。企业应用 平台的上传控件应保持紧凑、低噪声，并清楚表达文件名、格式约束和后续处理动作。

  • 默认高度 42px
  • 圆角 8px
  • 支持 .zip 参数包
  • 跟随按钮主色 #00D157

何时使用

  • 用于 Tiktok 上传、素材处理、媒资汇总等需要把文件交给 Agent 继续执行的任务流程。
  • 任务参数类上传优先使用上传按钮加文件列表，列表展示文件名、上传状态、失败重传和删除动作。
  • 聊天输入区的附件入口使用图标按钮，不在首屏展开完整上传面板，避免打断自然语言输入。
  • 已上传文件应保留可识别文件名；重新选择或继续上传时复用同一文件选择入口。
  • 格式、大小或解析失败时直接在上传控件下方给出错误说明，不只依赖 toast。

API

属性 说明 类型 默认值
variant 上传形态。基础用法为绿色按钮，拖拽上传为灰底虚线区域，照片墙为图片方格入口。 button | drag | picture-card button
accept 允许上传的文件类型。参数包默认限制为 .zip，照片墙默认限制为图片。 string .zip,application/zip
multiple 是否支持多文件选择或批量拖拽。 boolean false
fileList 已上传文件列表，列表项包含文件名、状态、进度和删除/重试动作。 UploadFile[] []
status 单个文件上传状态。完成态仅展示对勾图标，上传中展示 loading 环和进度，失败态展示重试或错误反馈。 uploading | success | error -
progress 上传进度百分比。文件列表展示在右侧文案后，照片墙展示在蒙层 loading 下方。 number -
disabled 禁用上传入口，不响应文件选择，hover 时显示禁止光标。 boolean false
buttonText 基础用法按钮文案。 string 上传文件
dropTitle 拖拽上传主文案。 string 点击或拖拽文件到此处上传
dropHint 拖拽上传辅助说明。 string 支持 .zip 参数包，单次建议不超过 200MB
pictureText 照片墙上传入口文案。 string 上传图片
showRemove 是否展示删除按钮。照片墙删除按钮仅在图片卡片 hover 或聚焦时展示。 boolean true
confirmRemove 点击删除时是否弹出确认删除弹窗。 boolean true
onChange 文件选择或拖拽上传后触发。 (files: File[]) => void -
onRemove 确认删除文件后触发。 (file: UploadFile) => void -
onRetry 失败文件点击重试后触发，进入 uploading 状态。 (file: UploadFile) => void -
onDrop 文件拖入拖拽上传区域后触发。 (files: File[]) => void -
