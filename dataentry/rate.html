Data Entry / Rate

Rate 评分

评分用于表达质量、满意度、风险等级和推荐优先级，适合快速反馈、Agent 评估、任务复盘和素材质量标注。组件结构参考通用评分组件，以星形为默认字符，并保留半选、清除、只读、禁用、提示文案和笑脸分级能力。

  • 默认 5 项
  • 图标 24px
  • 间距 8px
  • 激活色 #F7BA1E

何时使用

  • 用于收集用户满意度、标记素材质量、评估 Agent 输出结果或展示轻量等级。
  • 评分结果需要表达连续细分时开启半星；只需要粗略反馈时使用整数星。
  • 仅展示历史评分、模型评分或不可编辑结果时使用只读，不要让用户误以为可点击。
  • 评分会触发提交、过滤或排序时，应在旁边显示当前分值或语义文案。
  • 需要明确的二元开关、单选项或精确数值输入时，不使用 Rate。

DOM Anatomy

API

属性 说明 类型 默认值
defaultValue 非受控初始评分。 number -
value 受控评分值。 number -
count 评分字符总数。 number 5
character 自定义字符，可根据索引返回不同内容。 ReactNode | (index) => ReactNode <IconStarFill />
allowHalf 是否允许半选。 boolean false
allowClear 再次点击当前值时是否清除评分。 boolean false
tooltips 每一项的提示文案。 string[] -
readonly 是否只读，只展示评分，不响应选择。 boolean false
disabled 是否禁用，表达流程不可操作。 boolean false
grading 是否使用笑脸分级。 boolean false
onChange 评分变化时触发。 (value: number) => void -
onHoverChange 鼠标经过的评分值变化时触发。 (value: number) => void -

Design Tokens

Token 值 说明
