Data Entry / VerificationCode

验证码输入框 VerificationCode

验证码输入框用于录入短信、邮箱、二次验证和敏感操作确认的一次性验证码。结构遵循通用组件 VerificationCode 的模式：外层容器统一管理长度、状态和分隔符，内部由一组单字符输入框组成，并与 Input 输入框的尺寸、圆角、边框、hover、focus、错误和禁用状态保持一致；状态示例仅保留 Default、Hover、Focus、Error、Disabled。

  • 默认 6 位
  • 单格高度 44px
  • 圆角 8px
  • 五类状态展示

何时使用

  • 用于短信验证码、邮箱验证码、MFA、登录确认、敏感操作二次校验等短码输入。
  • 每个字符独立输入，完成一格后自动流转到下一格；粘贴完整验证码时应自动拆分填充。
  • 需要按组阅读时可配置分隔符，例如 3-3、4-2 或带横线的邮箱验证码。
  • 验证码错误、过期、发送冷却和禁用状态需要保留稳定高度，避免表单布局跳动；校验通过沿用默认视觉，不额外增加状态卡片。

基础用法

基础验证码

默认 6 位数字验证码，输入行为与一组受控 input 对齐。

短信验证码 请输入 6 位短信验证码

带分隔符

参考 常见 separator 结构，分隔符不参与输入，仅增强长码阅读。

邮箱验证码 - 分组形式：3 位 + 3 位

密码化输入

用于二次验证、交易密码或一次性安全码，内容可见性由 masked 控制。

安全码

块级宽度

在移动端或窄表单中使用 block 布局，单格等分占满容器宽度。

登录确认码

状态

Default

默认状态使用轻边框，单格保持清晰但不打断登录流程。

验证码

Hover

悬停时只改变边框颜色，与 Input hover 保持一致。

验证码

Focus

聚焦格使用品牌色边框，外层阴影为 0 0 0 3px color-mix(in srgb, var(--brand-5) 16%, transparent)。

验证码

Error

错误状态需要同步标记所有格，并给出可执行提示。

验证码 验证码错误，请重新输入

Disabled

发送频控、账号锁定或只读流程中使用禁用态。

验证码

尺寸

Size

验证码单格尺寸跟随 Input 体系：紧凑场景使用 30px，标准验证码默认使用 44px，关键确认流程可放大到 48px。

Small 30
Default 44
Large 48

API

属性 说明 类型 默认值
value 受控验证码值，按输入格顺序拼接。 string -
defaultValue 默认验证码值。 string ""
length 验证码长度，控制内部 input 数量。 number 6
size 单格尺寸，与 Input 体系对齐。 small | default | large default
status 语义状态，用于默认、错误和禁用反馈；校验通过沿用默认视觉，不额外增加状态卡片。 default | error | disabled default
interactionState 用于静态规范或受控演示的交互态，覆盖 Default、Hover、Focus 三类展示。 default | hover | focus default
separator 自定义分隔符，渲染在指定输入格之间，不参与 value 拼接。 (index: number, character: string) => ReactNode -
masked 是否隐藏输入内容；开启后以 maskCharacter 替代已输入字符，用于安全码场景。 boolean false
maskCharacter 密码化输入的替代字符；仅在 masked=true 时生效。 string "*"
formatter 输入格式化函数，可限制数字、字母或业务验证码字符集。 (inputValue, index, value) => string | boolean -
readonly 只读展示验证码。 boolean false
disabled 禁用输入，不可聚焦和编辑；视觉状态与 Select disabled 一致。 boolean false
onInput 单格输入变化时触发。 (inputValue, index, event) => void -
onChange 验证码整体值变化时触发。 (value: string) => void -
onFinish 验证码达到 length 后触发。 (value: string) => void -

设计 Token

Token 值 用途
--verification-cell-width 42px 默认验证码单格宽度。
--verification-cell-height 44px 默认验证码单格高度。
--verification-cell-font-size var(--font-style-title-2-size) 默认及获焦态验证码字符字号，复用 Text Styles 的 Title 2 语义。
--verification-gap 8px 验证码单格之间的间距。
--verification-separator-width 18px 分隔符占位宽度。
--verification-mask-color var(--input-text-color) 密码化替代字符颜色，沿用输入文字语义色。
--verification-mask-font-size var(--verification-cell-font-size) 密码化替代字符字号，与当前尺寸的验证码字符一致。
--verification-mask-text-align center 密码化替代字符的水平对齐方式，默认居中。
--input-radius var(--control-radius-default) 单格输入框圆角，复用控件默认圆角语义。
--input-border-color var(--color-border-default) 默认边框。
--input-hover-border-color var(--color-action-primary) hover 边框。
--input-focus-color var(--color-action-primary) 聚焦态内层品牌色边框。
--input-focus-shadow 0 0 0 3px color-mix(in srgb, var(--color-action-primary) 10%, transparent) 聚焦态外层浅色描边。
--input-error-color var(--color-status-error) 错误态边框。
--input-error-shadow var(--color-status-error) 错误态聚焦外层浅红色描边。
--verification-disabled-bg var(--color-bg-subtle) 禁用态背景，与 Select disabled 一致。
--verification-disabled-border-color var(--color-border-default) 禁用态边框，与 Select disabled 一致。
--verification-disabled-color var(--color-text-disabled) 禁用态输入文本。
--verification-disabled-opacity 0.6 禁用态整体透明度，与 Select disabled 一致。
