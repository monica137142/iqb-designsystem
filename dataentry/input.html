Data Entry / Input

Input 输入框

输入框用于录入、编辑和搜索单行文本，也可承载带前后缀的业务信息。企业应用 平台的输入框应保持清晰边界、稳定高度和低噪声反馈，优先服务任务配置、搜索筛选和对话输入。

  • 默认高度 38px
  • 圆角 10px
  • 边框 #DDE1E5
  • Hover / Focus 使用品牌绿

何时使用

  • 用于录入任务名称、搜索关键词、时间文本、邮箱、Cron 表达式等短文本信息。
  • 需要多行自然语言描述时使用 textarea，不要强行拉长单行输入框。
  • 内容长度不固定的对话指令、备注和评论可使用自适应高度，多行输入框随内容增高，超过最大高度后使用透明轨道细滚动条。
  • 带单位、图标、清除、字数统计等辅助元素时，应优先使用同一输入容器承载，避免控件碎片化。
  • 错误、成功、禁用等状态需要保留稳定高度，避免表单在反馈出现时跳动。

基础用法

基础输入框

用于任务名称、关键词、邮箱等单行文本录入。

搜索输入框

用于 Agent 列表、任务列表和对象池的快速筛选。

带单位输入框

用于超时时长、重试间隔等带固定单位的配置项。

多行输入框

用于任务指令、背景信息、补充说明等长文本录入。

自适应高度

用于对话指令、评论和备注等内容长度不固定的多行录入，超过最大高度后右侧仅展示细滚动条。

状态

Default

默认状态使用轻边框，不主动争夺注意力。

Hover

悬停时边框变为品牌绿，与选择器保持一致，不出现外发光。

Focus

聚焦时使用品牌绿边框与浅色 focus ring。

Error

错误状态需给出可执行的修正提示。

Disabled

禁用态保留文本可读性，但明确表达不可编辑。

尺寸

Size

默认表单输入框高度为 38px；紧凑工具栏可使用 30px，大型输入用于关键表单或宽松布局。

字数提示

字符计数

用于有长度上限的名称、标题、关键词和长文本。超出限制时，输入框边框与计数提示同步转为错误状态。

交互状态

Placeholder

占位文案应说明输入内容，不替代 label。

Affix

前后缀用于搜索、单位、协议、后缀说明等轻量辅助信息。

API

属性 说明 类型 默认值
type 输入框类型，透传原生 input 类型。 text | search | email | password | time | datetime-local text
size 输入框尺寸。 small | default | large default
status 语义状态，用于校验反馈和禁用展示；hover、focus 由 interactionState 表达。 default | success | error | disabled default
interactionState 用于静态规范或受控演示的交互态；与 status 组合后覆盖 default、hover、focus、error、disabled 五类状态。 default | hover | focus default
placeholder 输入提示文案，不替代字段 label。 string -
prefix 前置图标或文本，例如搜索图标、协议前缀。 ReactNode -
suffix 后置图标或文本，例如单位、清除、状态提示。 ReactNode -
allowClear 有输入内容时展示右侧线性清除按钮；为空时隐藏。 boolean false
showCount 展示内嵌字数提示，单行位于右侧居中，多行位于右下角。 boolean false
autoSize 多行输入框随内容自动增高；超过最大高度后展示透明轨道细滚动条，不允许手动拖拽改变尺寸。 boolean | { minRows?: number; maxHeight?: number } false
maxLength 字数上限；超出时进入 overLimit 样式。 number -
overLimit 超出字数上限时的错误态，输入框边框和计数提示同步变红。 boolean false
disabled 禁用输入框，不可编辑，保留可读文本。 boolean false
showHelp 显示辅助说明或校验反馈。 boolean false
