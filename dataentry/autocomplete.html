Data Entry / AutoComplete

自动补全 AutoComplete

自动补全用于在输入、聚焦或查询时给出候选建议，帮助用户用关键词快速定位 Agent、任务、报告、连接和模板等对象。控件继承 Input 输入框的高度、圆角与聚焦描边，并在输入框下方悬浮展示可键盘导航的建议菜单。

  • 输入框默认高度 38px
  • 圆角 10px
  • 浮层间距 8px
  • 选项最小高度 34px
  • 细滚动条 4px

何时使用

  • 用户知道大致关键词，但完整名称、ID、描述或对象分类较多，需要边输入边缩小范围。
  • 候选项可以被搜索、过滤、分组或实时计算结果数量，例如 Agent、任务、报告、连接和模板。
  • 候选项随输入动态变化，或需要在输入框内保留自由文本时使用；仅从固定集合选择且无需输入时使用 Select。
  • 候选项是层级路径时使用 Cascader；需要在长文本中插入对象时使用 Mentions。

基础用法

输入显示

输入后根据当前内容生成 3-5 条联想字段，未输入时保持菜单收起。

聚焦即展示最近或推荐候选；输入后只保留匹配项，无匹配时展示空状态。

状态

Default

默认状态仅展示轻边框；浮层在有候选项或输入激活时出现。

Hover

悬停只改变输入框边框颜色，不打开浮层。

Focus

聚焦时使用品牌色边框，并增加与输入框一致的浅绿色外描边。

  • 大盘数据分析助手Agent
  • 用户数据看板Report

Error

必选对象没有匹配项时进入错误态，说明应告诉用户如何修正。

未找到匹配 Agent，请检查名称或切换业务分类

Disabled

禁用态不响应输入、清除和候选项选择。

Empty

无结果时保持浮层宽度和位置稳定，不用 Toast 替代空状态。

没有找到匹配的可用硅基实习生

尺寸

Size

尺寸继承 Input：紧凑筛选使用 30px，标准表单使用 38px，关键检索入口使用 44px。

交互规则

  • 下拉菜单始终悬浮在输入框下方，不占用示例卡片或表单布局高度。
  • 输入显示类示例在有输入时打开浮层；获焦显示类示例聚焦即展示推荐，输入后筛选匹配项。
  • 上下方向键移动 active 选项，Enter 选择，Escape 关闭浮层，Tab 按正常表单焦点顺序离开。
  • 命中文本不使用绿色高亮或加粗；候选项选中后使用灰底高亮，复杂选项悬停和选中不增加描边。
  • 查询模式可在输入框右侧展示搜索图标；不确定类目展示实时 results，确定类目使用不可选分组标题。
  • 搜索类输入建议开启 allowClear；清除后输入框保留焦点，浮层同步切换为空态、最近使用或收起状态。

defaultValue 非受控输入框初始值。 string -

suffix 输入框右侧内容，例如查询模式中的搜索图标或清除按钮。 ReactNode -

status 语义状态，用于校验反馈和禁用展示。 default | error | disabled default

open 受控展开状态，用于聚焦显示、远程搜索或自定义输入框场景。 boolean -
notFoundContent 无匹配项时的空态内容；基础用法中可为空，不自动生成“xxx 标签”。 ReactNode -
onSearch 输入变化时触发，用于远程检索、更新候选项或刷新 results 数量。 (value) => void -
onSelect 选择候选项时触发。 (value, option) => void -
