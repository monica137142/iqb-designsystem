Data Entry / Form

Form 表单

表单用于收集、校验并提交结构化任务配置。IQB Agent 平台中常用于创建 Agent、 配置自动化任务、编辑店铺资料和批量操作参数，布局应保持字段关系清晰、错误反馈贴近字段。

  • 默认控件高度 38px
  • 标签宽度 96px
  • 字段间距 18px
  • 支持水平、垂直与行内布局

何时使用

  • 用于需要用户输入多个字段并统一提交的场景，例如创建任务、编辑策略、配置 Agent。
  • 字段之间存在明确依赖或校验规则时，使用表单承载状态、帮助信息和错误反馈。
  • 简单开关或单一即时操作不应放入完整表单，可直接使用 Switch、Checkbox 或 Button。
  • 错误信息应放在对应字段下方，避免只在页面顶部或 toast 中说明。

基础用法

任务创建表单

水平表单适合桌面端任务配置，标签固定宽度，输入控件在右侧对齐。

布局

垂直布局

适合窄容器、弹窗和移动端，标签位于控件上方。

行内布局

适合表格上方筛选，不承载复杂帮助信息。

业务域
  • 商品运营
  • 广告投放
状态
  • 运行中
  • 已暂停

状态

Default / Focus

默认使用轻边框；聚焦时使用品牌绿描边和外发光。

Error / Success / Disabled

校验状态跟随字段展示；禁用态保持可读但不可编辑。

API

属性 说明 类型 默认值
layout 表单布局方式。 horizontal | vertical | inline horizontal
labelWidth 水平布局标签宽度，用于保持字段起始线对齐。 number | string 96
required 是否展示必填标识。 boolean false
status 字段校验状态。 error | success | warning -
help 字段下方的帮助或错误文案。 string -
disabled 是否禁用表单或单个字段。 boolean false

设计 Token

Token 值 用途
--form-control-height 38px 默认输入控件高度。
--form-label-width 96px 水平布局标签宽度。
--form-item-gap 18px 字段组纵向间距。
--form-control-radius 8px 输入、选择和文本域圆角。
--form-required-color #D92D20 必填星号与错误状态颜色。
--form-focus-shadow 0 0 0 3px rgba(34, 181, 115, 0.16) 聚焦态外发光。
