Data Entry / Cascader

联级选择 Cascader

联级选择用于从多层结构中逐级定位目标。本规范围绕 IQ Buddy Agents 工作台建立，覆盖实习生范围、业务线、任务类型、会话路径和权限路径等选择场景；支持默认收起、单选、允许清除、多选标签省略和逐级动态加载。

  • 触发器默认宽高 320 × 38px
  • 圆角 10px
  • 浮层列宽 155px
  • 选项最小高度 34px
  • 细滚动条 4px
  • 同页仅展开一个下拉菜单

何时使用

  • 当选项存在稳定的父子层级，并且用户需要看清路径关系时使用，例如「全体实习生 / 种草业务线 / TikTok 上传」。
  • 当需要跨层级批量授权或筛选时可启用多选；多选通过复选框命中区勾选，选项 tab 区域仅负责展开或收起子级。
  • 当子级数据来自远程接口或体量较大时使用动态加载；每一级首次进入时展示加载环，数据返回后再展开下一级。
  • 当用户只需要在扁平集合中选择一个值时，优先使用 Select；当需要在页面内持续切换分类时，优先使用 Tabs 或 Segmented。

基础用法

点击展开

选择框默认展示占位文案，点击后展开分列菜单；选择末级后回填完整路径并自动收起。

hover 展开

选择框默认收起；展开后悬停父级切换下一级，点击末级后完成选择。

允许清除

清除已选路径

已选路径可快速清空，适合筛选条件和非必填配置项。

多选

标签省略

多选标签超出选择框宽度时，尽可能展示完整标签，其余合并为不可删除的 +n 计数。

动态加载

按需加载子级

每一级首次进入时用加载环替换右侧进入图标，数据返回后再展开下一级选项。

交互规则

  • 选择框和下拉菜单默认不选中、默认收起；展开后点击页面其他区域自动收起，页面内同时仅保留一个下拉菜单展开。
  • 单选触发器展示完整路径；路径过长时保留末级名称可见，并通过 tooltip 或详情区补全路径。
  • 多选下点击复选框区域执行勾选或取消勾选，点击选项 tab 区域执行展开或收起下一级菜单。
  • 多选父子联动：勾选父级会勾选其全部子级，取消父级会取消其全部子级；下级全选时上级显示勾选，下级未全选时上级不显示勾选。
  • 多选选择框标签优先展示上一层级勾选标签；父级已展示时不再展示其子级，标签超出宽度时合并为不可删除的 +n。
  • 动态加载每一级首次进入时，用加载环替换右侧进入图标；加载完成后再展示下一列。
  • 键盘操作使用方向键在当前列移动，右方向进入子级，左方向返回父级，Enter 选择，Escape 关闭浮层。

API

属性 说明 类型 默认值
options 层级选项数据，推荐包含业务范围、分类、Agent 或任务节点。 CascaderOption[] []
value 当前选中路径；单选为路径数组，多选为路径数组集合。 string[] | string[][] -
placeholder 未选择时的占位文案。 string 请选择 Agent / 任务类型
expandTrigger 子级展开方式。表单默认点击；hover 模式仅用于桌面端轻量导航。 "click" | "hover" "click"
allowClear 是否允许清除已选路径。清除入口仅在已有选中值时出现。 boolean false
multiple 是否启用多选。多选下复选框负责勾选，选项 tab 负责展开或收起子级。 boolean false
collapseTags 多选标签是否省略展示。超出选择框宽度时优先展示父级标签，其余合并为 +n。 boolean false
loadChildren 逐级异步加载子节点。加载中用加载环替换当前项右侧进入图标，完成后展开下一级。 (option, path) => Promise<CascaderOption[]> -
changeOnSelect 是否允许选择非叶子节点。筛选场景可开启，配置提交场景默认关闭。 boolean false
status 语义状态，用于默认、错误或禁用反馈；hover、focus 由交互状态自动触发。 "default" | "error" | "disabled" "default"
onVisibleChange 下拉菜单展开或收起时触发。同一页面仅允许一个级联下拉保持展开。 (open) => void -
onChange 选中路径变化时触发，单选返回路径数组，多选返回路径数组集合及完整节点信息。 (value, options) => void -
