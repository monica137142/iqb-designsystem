    Radius 圆角

    圆角用于表达组件边界、层级和形态。IQB Design 使用 Small、Default、Large、XLarge 和 Full 五档 Token，其中 Default 为默认圆角。

    使用原则

    先判断组件的边界语义，再选择 Token。圆角不能代替层级、间距或组件尺寸本身。

    01

    按语义选择

    高频操作、内容容器与浮层使用不同层级，避免所有组件采用同一个圆角。

    02

    只调用 Token

    组件通过基础圆角变量取值，不在局部样式中新增散落的数值。

    03

    完整圆角限形态

    radius-full 只用于圆形、胶囊、头像和状态点，不用于普通卡片。

    基础 Token

    radius-style-default 提供以下固定映射。切换主题只改变映射，不改变组件尺寸、布局与交互范围。

    TokenValue使用场景示例
    radius-small4pxCheckbox、Tag、代码片段Small
    radius-default6pxButton、Side nav itemDefault
    radius-large8pxInput、Card、CollapseLarge
    radius-xlarge12pxDropdown、Popover、Modal、媒体预览XLarge
    radius-full9999pxAvatar、Icon Button、状态点

    调用方式

    样式主题在应用根节点声明，组件只消费与自身语义对应的基础 Token。

    1. 定义默认映射

    圆角主题集中维护完整的基础变量。

    .radius-style-default {
  --radius-small: 4px;
  --radius-default: 6px;
  --radius-large: 8px;
  --radius-xlarge: 12px;
  --radius-full: 9999px;
}

    2. 在组件中调用

    根容器选择主题，业务组件无需感知映射细节。

    <body class="radius-style-default">
  <div class="card">...</div>
</body>

.card {
  border-radius: var(--radius-large);
}

    维护规则

    • 新增组件时优先复用现有 Token；只有形成跨组件的稳定语义后才扩展基础层。
    • 拼接结构可直接使用 0 消除相邻边圆角；它是结构性例外，不属于基础圆角档位。
    • 主题切换不得改变点击区域、组件高度或内容布局。
