Styles / Typography

Text 字体

统一字体、字号、字重与行高，为页面和组件建立清晰、稳定的文字层级。

  • Sans / Mono 两类字体族
  • 9 类全局页面文字角色
  • 400 / 500 / 600 三档字重
  • 12–32px 页面字号范围
  • 覆盖标题、数据、正文、控件与辅助信息

使用原则

  • 全局页面按 Display、三级标题、两级正文和两级 Caption 共九类真实角色组织文字层级。
  • 界面文字默认使用 font-sans；代码、Token、API 字段和需要对齐的数值使用 font-mono。
  • Display 与 Title 使用 Semibold 600；正文和 Caption 使用 Regular 400，其强调样式使用 Medium 500。
  • 每个 Style Token 固定组合 font-size、font-weight 和 line-height，不拆分调用或临时调整。
  • 优先按内容角色选择 Title-1、Title-2、Body 等 Font Style，不按 HTML 标签机械选型。
  • 每个全局页面只使用一个页面标题，章节标题保持连续层级；卡片内部从容器标题开始。
  • 颜色、间距和字体规格分别使用对应 Token；字体样式不承载状态颜色或布局间距。

颜色

以当前色板的品牌 500 色为主色基准，按品牌色、中性色、功能色与遮罩值组织颜色规范。 色阶编号从 50 到 900，数值越大颜色越深，500 作为常规态或语义基准色。

  • 品牌色 #1CC749
  • 11 阶梯度 50-950
  • 功能色覆盖 Danger / Warning / Info
  • 适用于组件、状态、遮罩与主题变量

色彩角色

品牌色 用于主按钮、关键操作、选中态、聚焦态和高价值数据。
中性色 用于文本、边框、分割线、背景和弱化信息层级。
功能色 用于错误、警告、提示、链接、信息反馈和状态徽标。

遮罩

遮罩用于压低背景内容的视觉权重，让弹窗、抽屉、确认面板和局部加载状态成为当前操作焦点。 黑色遮罩用于阻断式浮层，白色遮罩用于局部加载；透明度根据阻断程度选择。

弹窗遮罩

用于 Modal、确认弹窗和高阻断任务，背景需要明显退后。

rgba(0, 0, 0, 0.45)

抽屉遮罩

用于 Drawer、侧边配置和局部编辑任务，保留背景上下文。

rgba(0, 0, 0, 0.35)

局部加载遮罩

用于表格、卡片和表单局部加载，弱化内容但不制造强阻断。

rgba(255, 255, 255, 0.72)

Overlay

  • color-overlay-modal overlay-modal rgba(0, 0, 0, 0.45) Modal / 确认弹窗
  • color-overlay-drawer overlay-drawer rgba(0, 0, 0, 0.35) Drawer / 侧边配置
  • color-overlay-loading overlay-loading rgba(255, 255, 255, 0.72) 局部加载 / 表格遮罩

使用原则

  1. 页面和组件优先使用 Semantic Token，不直接调用 Primitive Color。
  2. Primitive Color 仅作为基础色板和 Semantic Token 的取值来源。
  3. Component Token 应优先引用 Semantic Token。
  4. 文字用途优先使用 color-text-* Semantic Token，不直接使用 gray-neutral-900、gray-neutral-600 等 Primitive Token。
  5. Brand / Action Semantic Token 随 Theme 改变。
  6. Text、Background、Border 等中性色语义默认跨 Theme 保持一致。
  7. Success / Warning / Error / Info 表达固定状态含义，不随 Brand Theme 改变。
  8. 不要因为单个组件需求随意增加 Semantic Token；只有出现跨组件、重复使用的颜色语义时才新增。
  9. 如果现有 Semantic Token 可以表达用途，不创建新的 Token。

调用示例

font-family 在应用根节点统一设置并由子元素继承。Style Token 只组合 font-size、font-weight 与 line-height；页面和组件直接调用 Style Token，不再自行组合基础 Token。

1. 设计系统内部定义

根节点统一声明 font-family；基础样式层为每个 Font Style 组合字号、字重与行高。

:root {
  font-family: var(--font-sans);
}

.font-style-title-2 {
  font-size: 20px;
  font-weight: 600;
  line-height: 28px;
}

2. 页面与组件调用

业务代码按内容角色直接使用 font-style-title-2，无需再次声明字号、字重或行高。

图标 ICON

Icon 是界面中的语义型 UI 元素，不作为装饰图形使用。优先复用现有 Design System 或 Icon Library 中同语义图标； 仅当现有资源无法覆盖业务语义时，AI 才允许按本章节规则自动生成 SVG Icon。

Icon 基础原则

Reuse first. Generate only when necessary. 语义不明确时优先选择通用、易理解的表达，不为了视觉效果创造复杂图形。

  1. 已有同语义 Icon 时，直接复用，不重新生成近似版本。
  2. 缺少现成 Icon 时，允许 AI 自动生成符合本规范的 SVG。
  3. Icon 只表达功能语义，不作为装饰插画使用。
  4. 同一语义在同一页面必须保持同一图形。
  5. 语义清晰度优先于视觉新颖度。
Icon Canvas

统一使用 24×24 标准画布与 2px 安全边距；实际显示尺寸跟随相邻文字字号、组件高度和视觉平衡调整。

  • Canvas：24 × 24
  • Safe area：2px
  • 主要图形保持视觉居中，避免贴边。
  • 不要因为显示尺寸变化改变 viewBox。
Icon Size

Icon 尺寸默认与相邻文字字号保持一致或接近，并根据组件高度和视觉平衡进行调整。

  • Icon 尺寸不设置推荐的固定尺寸阶梯。
  • 图文组合中，Icon 与相邻文字字号保持一致或接近。
  • Button、Menu、Navigation、Form、Toolbar 等组件内的 Icon，按组件高度、内边距和视觉重量进行微调。
  • 独立操作入口、空状态或功能入口中的 Icon，可根据版面层级放大，但仍以语义角色和视觉平衡为准。
Stroke Style

默认线性 Icon 固定使用 2px 描边、圆角线帽和圆角连接。Icon 尺寸变化时不改变描边粗细。

Do / Don't 示例

生成 Icon 时保持简单、几何、统一视觉重量，不用 Emoji、Unicode 符号、CSS 拼接或网络图片替代正式 Icon。

DO
  • 24×24 Canvas
  • 2px Stroke
  • Round Linecap / Round Linejoin
  • currentColor
  • 简洁几何结构与统一视觉重量
  • 优先复用现有 Icon
DON'T
  • 混用 1px / 1.5px / 2.5px 描边
  • 用 Emoji 或 Unicode Symbol 代替 Icon
  • 随机使用 Filled Icon
  • 写死 HEX Color
  • 绘制复杂细碎 SVG
  • 为相同语义重复生成不同图形
  • 用 CSS Border 或大量 div 临时拼接 Icon

--radius-default 6px 默认圆角，用于高频操作与导航元素。 Button、Side nav item。
--radius-large 8px 大圆角，用于输入区域和内容容器。 Input、Card、Collapse。
--radius-xlarge 12px 超大圆角，用于浮层、大型容器和媒体承载区域。 Dropdown、Popover、Modal、媒体预览。
--radius-full 9999px 完整圆角，元素应呈现胶囊或圆形。 Badge、Switch、Avatar、Pill、Scrollbar thumb。

投影 Shadow

基础页面结构主要依赖边框与留白，投影集中用于弱层级、悬停、浮层和焦点反馈。 投影 token 按使用语义命名，组件应先判断层级关系和交互状态，再选择对应投影语义。

Surface

弱投影

用于静态轻量容器、细微层级提示和低强调背景卡片。

Hover

轻量悬停

用于卡片 hover、列表项强调和低层级浮起反馈。

Overlay

浮层容器

用于 Select、DatePicker、菜单和临时面板。

Focus Ring

焦点环

用于键盘焦点、输入聚焦；选择器聚焦通过 --selector-focus-shadow 固定引用该投影。

投影语义

Token 值 语义 典型组件
--shadow-surface 0 2px 6px rgba(20, 28, 36, 0.06) 弱层级投影，用于让静态轻量容器从背景中轻微浮起。 低强调卡片、统计卡片、轻量预览容器。
--shadow-hover 0 4px 12px rgba(20, 28, 36, 0.08) 交互悬停投影，用于表达可点击模块被指向或轻微抬升。 Card hover、列表项 hover、可点击模块。
--shadow-overlay 0 12px 28px rgba(20, 28, 36, 0.12) 浮层投影，用于临时覆盖在页面之上的面板和菜单。 Select Dropdown、DatePicker Panel、Popover、Menu。
--shadow-focus 0 0 0 3px rgba(var(--brand-rgb), 0.16) 焦点环投影，用于键盘可达性、输入聚焦和需要明确定位当前操作对象的控件。 Input、Select、Button、Slider、Segmented Control、主题选择卡。
--selector-focus-shadow var(--shadow-focus) 选择器类组件获焦或展开时的固定投影参数，统一映射到 Focus Ring。 Select、DatePicker、TimePicker、Pagination Size Select、主题/色板选择器。

主题 Theme

当前站点提供 IQ 主题、IQ Buddy 主题和 test 主题 1。主题之间保持组件结构一致， 仅替换品牌色阶、焦点态、局部圆角和字体栈等基础变量，遮罩与中性色保持统一。

IQ 主题

以 iQIYI 标准绿色为品牌主色，适用于默认产品界面。

IQ Buddy 主题

使用更沉稳的绿色色阶，适用于 Buddy 产品语境。

test 主题 1

以蓝色为主色，并保持统一的 Default 默认圆角。

变量范围

Brand --brand-50 到 --brand-900、文本色、边框色和 RGB 值。
Interaction hover、focus、focus ring、输入框聚焦与数字输入框聚焦。
Shape & Font 控件圆角、主题字体栈和组件内需要跟随品牌变化的基础样式。

维护原则

  • 新增主题时先补齐品牌色阶，再校验组件 hover、focus、disabled 和 error 状态。
  • 组件样式优先读取全局变量，避免在组件内部写死可主题化的品牌值。
  • 主题差异只能改变视觉语义，不改变组件结构、交互路径和可访问性表达。
