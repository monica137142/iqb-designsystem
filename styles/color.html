Styles / Color

Color 颜色

颜色体系由品牌色、中性灰、功能色和语义色组成。品牌色与功能色色阶使用 0–9 编号， 中性灰使用 0–13；深色端增加页面、顶栏、容器与浮层阶梯，组件通过 Semantic Token 获取亮暗模式下的实际颜色。

  • 品牌色 var(--brand-5) · brand-5
  • 品牌色与功能色 0–9 · 中性灰 0–13
  • 功能色覆盖 Success / Warning / Danger / Info
  • 支持 Light / Dark
  • Primitive → Semantic → Component

使用原则

  • 色板编号属于 Primitive Color；品牌色与功能色使用 0–9，中性灰使用 0–13，品牌种子固定为 5。
  • 页面和组件优先调用 Semantic Token，不直接使用基础色阶或 Hex 色值。
  • 中性灰切换会更新 UI 前景色和背景色，但组件代码仍只调用 color-text-*、color-bg-*、color-border-*。
  • Light 与 Dark 分别选择合适的色板编号，不要求同号，也不反转原始色阶。
  • Success、Warning、Danger、Info 不跟随品牌色变化，确保状态认知稳定。
  • 只有出现跨组件、重复使用的颜色含义时才新增 Semantic Token；单一组件差异放入 Component Token。

色板

基础色板包含品牌色、中性灰和功能色。组件不直接调用色阶，而是通过 Semantic Token 建立稳定用途。

品牌色色阶

使用 Ant Design HSB 色板算法生成 0–9；所选种子色固定放在 brand-5。

    中性灰色阶

    中性灰使用 0–13 共 14 个层级：0–3 用于亮色画布、容器与弱边界，4–9 用于文字、图标及强边界，10–13 用于暗色模式的弱化区域、浮层、容器和页面画布。组件应通过 Text、Background、Border 等语义色调用，不直接绑定色阶。

      功能色色阶

      功能色保持跨品牌稳定：Success 为 var(--brand-5) 生成色阶；Warning 使用日暮、Danger 使用薄暮、Info 使用拂晓蓝，色值来源于 Ant Design 官方色板。

      语义色 Semantic Color

      一个语义 Token 同时声明 Light 与 Dark 的基础色板编号；组件只引用语义，不直接引用 Hex。

      调用示例

      只有当一种颜色含义会跨组件、重复使用时，才新增 Semantic Token；仅服务于单一组件的颜色差异，应定义为 Component Token。

      Semantic Token

      例如“主要操作背景”同时用于 Button、Checkbox、Radio 和 Switch，属于跨组件共享含义。

      color-action-primary → brand-5
      Component Token

      例如只有 Button 需要单独调整主要按钮背景，应放在 Button Token 中，不新增全局语义。

      button-primary-bg → var(--color-action-primary)
