Navigation / Steps

Steps 步骤条

Steps 用于呈现多步骤任务的当前位置和完成进度，帮助用户理解流程结构、预期路径和后续动作。

  • 流程进度
  • 支持水平 / 垂直
  • 支持状态
  • 支持可点击
  • 适合向导流程

何时使用

  • 用于线性或近线性的多步骤流程，不用于普通状态展示。
  • 步骤名称应描述阶段目标，而不是具体按钮动作。
  • 当前步骤、已完成步骤和异常步骤需要有可区分状态。
  • 当步骤较多或文案较长时使用垂直步骤条。
  • 允许回退时应明确哪些步骤可点击，避免误导用户。

基础用法

基础 Steps

由多个 Step 组成，每个步骤包含 title、description 和自动计算的 status，通过 current 指定当前步骤。

步骤状态

wait / process / finish / error

Steps 可根据 current 自动判断状态，也可以在某个 Step 上单独指定 status。

带描述的步骤条

title + description

每个步骤可以同时展示步骤名称和补充说明，用于需要解释任务状态或审核节点的流程。

自定义图标步骤条

SVG icon

通过 icon 将圆形节点内的数字替换为 SVG 图标，当前步骤使用 loading 环表示处理中状态。

下方文字的步骤条

下方文字的步骤条

通过 titlePlacement="vertical" 将标题和说明放在节点下方，适合步骤较少且需要居中展示的流程。

垂直步骤条

vertical

通过 direction="vertical" 使用纵向结构，适合步骤说明较长、流程节点较多或需要逐项阅读的场景。

箭头步骤条

单行箭头步骤条

仅展示步骤标题，适合空间紧凑且流程名称清晰的场景。

常规状态

错误状态

双行箭头步骤条

展示标题和说明，用于需要补充当前阶段含义或操作提示的流程。

可点击切换步骤条

单行可点击步骤条

仅展示标题，点击圆 icon 步骤条或箭头步骤条中的任一步骤即可切换当前索引。

展示标题和说明，点击圆 icon 步骤条或箭头步骤条中的任一步骤即可切换当前索引。

圆ICON步骤条

tab导航样式

在导航项中同时展示标题和说明，用于需要解释每个配置阶段含义的流程。
