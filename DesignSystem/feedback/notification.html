Feedback / Notification

Notification 通知提醒

Notification 用于展示较完整的异步结果、系统提醒或任务状态，通常出现在页面角落并可保留更长时间。

  • 角落浮层
  • 支持标题和描述
  • 可带操作
  • 适合异步结果

何时使用

  • 需要在页面角落展示完整的异步结果、系统状态、后台任务进度或稍后处理事项时使用 Notification。
  • 通知内容应包含清晰的 title 和 content，帮助用户快速判断事件来源、结果和下一步动作。
  • 内容超过一行、需要操作按钮、需要持续停留或需要通过 id 更新状态时，优先使用 Notification。
  • 只需要简短即时反馈时使用 Message；需要阻断用户决策时使用 Modal 或 Popconfirm。

基础用法

基础 Notification

通过调用 Notification 展示一条包含 title 和 content 的通知。

默认停留 3s，多个通知会按顺序堆叠并离场。

不同通知类型

状态类型

Info、Success、Warning、Error 使用一致的通知结构，通过语义图标和颜色区分状态。

信息通知

这里展示需要用户关注的一般信息。

操作成功

数据已保存并同步到最新版本。

请注意

部分内容尚未填写，请确认后继续。

提交失败

网络异常，请检查后重新提交。

更新通知

id 更新

通过唯一 id 更新已经存在的 Notification，避免重复创建多条通知。

处理中状态会在同一条通知内更新为处理成功。

自定义操作内容

操作区域

通知中可以追加 Button、Link 或自定义操作内容，例如上传完成后查看文件。

选择一个操作内容案例查看通知。

自定义图标

图标配置

通知支持按场景替换图标形态，也可以隐藏图标，仅保留标题和正文。

选择一个图标案例查看通知。

不同展示位置

右侧位置

通知默认从页面右上角出现，可设置为 bottomRight 让通知从右下角进入并向上堆叠。

右上通知会从右侧滑入。

全局配置

Notification.config()

统一配置默认展示位置、默认持续时间和最大通知数量。

当前默认：topRight / 3s / maxCount 5。
