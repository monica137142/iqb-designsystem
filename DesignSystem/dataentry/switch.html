Data Entry / Switch

Switch 开关

开关用于即时切换单个配置项的开启或关闭状态。企业应用平台中常用于启停自动化能力、开启通知、 控制定时任务和高频偏好项，交互结果应即时生效并保持状态清晰。

  • 默认尺寸 36×20px
  • 滑块尺寸 16px
  • 开启主色 var(--color-action-primary)
  • 支持禁用态

何时使用

  • 用于即时生效的二元状态，例如启用任务、开启提醒、允许自动重试。
  • 若切换后需要二次确认、填写原因或提交表单，应优先使用 Button 或 Checkbox。
  • 开关文案应描述开启后的状态，避免使用模糊动作词。
  • 涉及异步保存或确认成本较高的配置，建议改用 Button 或表单提交承载。

基础用法

基础开关

用于单个即时配置，点击后状态立即切换。

开关组

用于多个互不依赖的即时配置项。

组合类型

带文字开关

当空间允许且状态需要更明确时，可在轨道内展示开/关短文本。

状态

Off

关闭态使用中性灰轨道，表示配置未启用。

On

开启态使用品牌绿轨道，并将滑块移动到右侧。

Disabled

禁用态保留当前开关状态，但不可切换。

Loading

切换后进入短暂 loading，不允许连续点击；完成后同步最终状态。

尺寸

Size

默认使用 36×20px 的紧凑规格；高密度区域可使用 small，强调性配置可使用 large。

API

属性 说明 类型 默认值
checked 当前是否开启；开启态使用主操作色，不附加常驻 Focus Shadow。 boolean -
defaultChecked 默认是否开启。 boolean false
disabled 是否禁用开关；禁用时保留当前状态并以 50% 不透明度展示。 boolean false
loading 切换处理中状态，展示加载并禁止连续点击。 boolean false
size 开关尺寸。 small | default | large default
checkedText 开启态轨道内短文本。 string -
uncheckedText 关闭态轨道内短文本。 string -
onChange 状态变化时触发。 (checked) => void -
