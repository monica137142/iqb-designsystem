Feedback / Spin

Spin 加载中

用于表示内容正在加载或操作正在处理中，为等待过程提供持续、明确且不过度打扰的状态反馈。

  • Loading feedback
  • 局部 / 全屏
  • 支持延迟
  • 可自定义指示器

何时使用

当内容获取或操作执行需要等待，且无法准确展示完成进度时使用 Spin。局部操作只覆盖对应区域；可获得明确百分比时优先使用 Progress。

  • 数据请求、表格刷新、卡片加载等短时等待。
  • 表单提交或页面切换时，阻止用户重复操作。
  • 极短请求建议搭配 delay，避免加载图标快速闪烁。

API

Spin

属性 说明 类型 默认值
loading 是否显示加载状态；关闭后展示正常内容。 boolean true

设计 Token

Token值说明
--spin-colorvar(--color-action-primary)加载环与自定义图标的主色。
--spin-bgvar(--color-border-default)加载环轨道背景，使用默认边框语义色。
--spin-size20px默认加载环尺寸；小尺寸为 14px，大尺寸为 30px。
--spin-stroke2px默认加载环线宽；大尺寸使用 3px。
--spin-radiusvar(--radius-full)加载环圆角，使用全圆角语义 token。
--spin-tip-colorvar(--color-text-secondary)提示文字使用次级文本语义色。
--spin-tip-font-sizevar(--font-style-body-size)提示文字使用 Body text style。
--spin-tip-line-heightvar(--font-style-body-line-height)提示文字使用 Body text style 行高。
--spin-duration750ms默认加载环单次旋转时长。
--spin-overlay-bgvar(--color-overlay-black-strong)包裹内容及页面与大区域加载时的语义遮罩背景。
