Feedback / Skeleton

Skeleton 骨架屏

Skeleton 是为特定页面预先设计的加载状态。在产品开发阶段确认需要使用的页面并完成对应骨架稿，运行时仅在该页面的数据加载期间展示。

  • 结构占位
  • 适合首屏加载
  • 页面级设计稿
  • 按需使用

何时使用

  • 用于产品开发阶段已明确设计骨架稿的首屏、核心列表或详情页加载过程。
  • 骨架结构应与目标页面的信息层级、布局尺寸和响应式规则保持一致。
  • 加载时间极短、页面结构不稳定或未提供骨架设计稿时不使用，避免闪烁和额外维护成本。
  • 提交、轮询等明确任务进度使用 Spin 或 Progress；错误与空数据使用对应反馈组件。

基础用法

基础骨架屏

最简单的段落骨架屏效果，不包含动画。

常见业务结构

用户信息加载

适用于头像与多行用户信息同时加载的内容区域。

图文内容加载

适用于封面图片与摘要正文并列展示的内容区域。

内容与操作加载

适用于包含多行正文与底部操作按钮的内容区域。

动画

扫光动画

开启后使用统一节奏的扫光效果强化加载感知。

设计 Token

Token值说明
--skeleton-colorvar(--color-border-default)静态骨架与流光底色，随明暗主题切换。
--skeleton-highlight-colorcolor-mix(in srgb, var(--color-border-default) 65%, var(--color-border-strong))由默认与强边框语义色混合的柔和高光，在暗色主题中仍保持可见。
--skeleton-radiusvar(--radius-small)文本、图片及方形头像的基础语义圆角；圆形头像和按钮除外。
--skeleton-text-heightvar(--font-style-body-size)段落占位高度，对应 text-body Text Style。
--skeleton-gap10.5px行盒高度减去占位高度，保持与默认正文相同的垂直节奏。
--skeleton-avatar-size40px头像骨架默认宽高。
--skeleton-image-width72px图片骨架默认宽度，可由页面骨架稿覆盖。
--skeleton-image-height48px图片骨架默认高度，可由页面骨架稿覆盖。
--skeleton-button-height32px按钮骨架高度，对应 Button Default 尺寸。
--skeleton-button-radiusvar(--radius-large)按钮骨架语义圆角，对应 Button Default。
--skeleton-animation-duration1.8s单次扫光周期。
--skeleton-animation-timing-functionlinear扫光匀速衔接，减少两次动画间的停顿感。
--skeleton-shimmer-size240% 100%扫光渐变背景尺寸，控制高光经过后的间隔。
