Feedback / Progress

Progress 进度条

Progress 用于反馈任务的完成程度与执行状态，帮助用户判断当前进展和最终结果。

  • 条形 / 环形 / 微型
  • Small / Medium / Large
  • 3 种语义状态

何时使用

  • 任务进度可量化时展示完成比例；上传、导出、批处理等长任务应同时给出任务名称。
  • 无法估计完成比例时使用 Spin；跨多个明确步骤的流程应使用 Steps。
  • 进度值限制在 0–100，完成后及时切换为成功状态；失败时保留现场并提供重试入口。
  • 文字应补充进度条无法表达的信息，例如剩余时间、已处理数量或当前阶段。

API

属性 说明 类型 默认值
percent当前进度，组件内部将数值限制在 0–100；持续加载模式下忽略。number0
type进度条形态。"line" | "circle" | "mini""line"
status任务语义状态，决定进度色及默认状态图标。"processing" | "success" | "error""processing"
showInfo是否展示进度值、状态文字或状态图标。booleantrue
format自定义信息内容；仅在 showInfo 为 true 时生效。(percent, status) => ReactNodepercent => `${percent}%`
statusIcon覆盖状态图标；默认按 Icon 语义映射为 Check / Close。IconSemantic | false由 status 决定
size语义尺寸，联动轨道或直径、描边和文字字号；mini 使用固定规格。"small" | "medium" | "large""medium"
strokeWidth覆盖默认轨道粗细或环形描边，单位为 px，取值必须大于 0。number由 type 与 size 决定
width条形长度或环形直径；数字按 px 处理，字符串须为合法 CSS 长度。number | string条形 "100%"；环形由 size 决定
