General / Button

Button 按钮

按钮用于触发即时操作、提交表单、打开任务流程或切换关键状态。IQB Agent 平台的按钮应保持紧凑、明确、低噪声，优先服务高频后台操作。

  • 基础高度 32px
  • 小尺寸 28px
  • 圆角 7-8px
  • 品牌主色 #22B573

何时使用

  • 用于触发明确、可预期的动作，例如新建对话、创建任务、保存修改、查看执行记录。
  • 同一操作区只保留一个主按钮，避免多个绿色按钮同时争夺注意力。
  • 列表行内操作优先使用轻量按钮或图标按钮，降低表格和卡片区域的视觉密度。
  • 危险动作需要与普通操作拉开颜色和语义距离，必要时结合二次确认。

基础用法

按钮类别

基础按钮用于覆盖页面、弹窗、表格行和任务流程中的常见操作。

图标按钮

仅图标按钮

用于高频工具操作，如关闭、刷新、编辑、查看执行记录。

图标+文字按钮

用于需要增强识别度的关键动作，文字仍然承担主要语义。

状态

Testing

用于训练、待上线、待处理等温和提醒状态。黄色主题下同样需要区分动作层级，避免所有提醒操作都使用同一种强调。

Info

用于信息提示、查看说明、执行记录、系统反馈等中性信息动作。蓝色主题用于辅助认知，不应替代品牌主操作。

Danger

用于删除、终止、不可逆操作。红色主题下应优先控制出现频率，常规页面只在确认区或行内危险操作中使用。

尺寸

Size

后台工具以紧凑尺寸为主，只有关键流程提交才使用 32px 或 36px。

交互状态

Disabled

不可用按钮保留原语义类型，但降低透明度，不响应 hover 强调。

Loading

提交中保留按钮宽度并显示加载状态，避免布局抖动。

API

type 按钮视觉类型。 primary | secondary | weak | dashed | solid | text | testing | info | danger default
size 按钮尺寸，后台列表和紧凑区域优先使用 small 或 medium。 small | medium | default | large default
status 业务语义状态，用于 Testing、Info、Danger 等主题按钮组。 default | testing | info | danger default
loading 展示加载态，并自动进入不可点状态，支持文字按钮与仅图标按钮。 boolean false

icon 可选前置图标，图标尺寸建议 14px，文字仍承担主要语义。 ReactNode -
iconOnly 仅图标按钮，需要提供可访问名称。 boolean false
aria-label 仅图标按钮必填，用于说明按钮操作含义。 string -

Data Entry / Input

Input 输入框

输入框用于录入、编辑和搜索单行文本，也可承载带前后缀的业务信息。IQB Agent 平台的输入框应保持清晰边界、稳定高度和低噪声反馈，优先服务任务配置、搜索筛选和对话输入。

  • 默认高度 38px
  • 圆角 10px
  • 边框 #DDE1E5
  • Focus 使用品牌绿

何时使用

  • 用于录入任务名称、搜索关键词、时间文本、邮箱、Cron 表达式等短文本信息。
  • 需要多行自然语言描述时使用 textarea，不要强行拉长单行输入框。
  • 带单位、图标、清除、字数统计等辅助元素时，应优先使用同一输入容器承载，避免控件碎片化。
  • 错误、成功、禁用等状态需要保留稳定高度，避免表单在反馈出现时跳动。

基础用法

基础输入框

用于任务名称、关键词、邮箱等单行文本录入。

搜索输入框

用于 Agent 列表、任务列表和对象池的快速筛选。

带单位输入框

用于超时时长、重试间隔等带固定单位的配置项。

多行输入框

用于任务指令、背景信息、补充说明等长文本录入。

状态

Default

默认状态使用轻边框，不主动争夺注意力。

Focus

聚焦时使用品牌绿边框与浅色 focus ring。

Error

错误状态需给出可执行的修正提示。

Disabled

禁用态保留文本可读性，但明确表达不可编辑。

尺寸

Size

默认表单输入框高度为 38px；紧凑工具栏可使用 30px，大型输入用于关键表单或宽松布局。

字数提示

字符计数

用于有长度上限的名称、标题、关键词和长文本。超出限制时，输入框边框与计数提示同步转为错误状态。

交互状态

Placeholder

占位文案应说明输入内容，不替代 label。

Affix

前后缀用于搜索、单位、协议、后缀说明等轻量辅助信息。

Data Entry / InputNumber

InputNumber 数字输入框

数字输入框用于录入数量、次数、时长、比例、间隔等数值型配置。IQB Agent 平台中的数字输入框应优先保证数值边界明确、单位清晰、步进可控，适合自动化任务和定时配置场景。

  • 默认高度 38px
  • 圆角 10px
  • 支持步进器
  • 支持单位后缀

何时使用

  • 用于重试次数、执行间隔、超时时长、随机窗口次数、百分比、价格等明确数值输入。
  • 当数值需要精确增减时启用步进器；仅做表格筛选或空间紧张时可隐藏步进器。
  • 带单位的数值应使用后缀固定展示，例如分钟、次、%、USD，避免把单位写进输入值。
  • 必须明确最小值、最大值和精度规则，避免自动化任务配置出现无效范围。

基础用法

基础数字输入

用于次数、阈值、数量等不需要单位解释的数字。

带单位数字输入

用于超时时间、重试间隔等带固定单位的任务配置。

步进器

显示步进器

适合值域较小、用户需要频繁微调的场景。

隐藏步进器

适合筛选、金额、长数字或需要直接键入的场景。

精度与范围

精度

小数场景需固定 precision，避免展示和提交不一致。

范围限制

到达边界时禁用对应步进方向。

状态

Default

默认状态保持轻边框和清晰输入区域。

Error

错误状态用于超出范围或格式无效。

Disabled

禁用态保留数值可读性，不允许键入和步进。

ReadOnly

只读态用于展示系统计算值，不呈现步进器。

尺寸

Size

数字输入框尺寸与 Input 保持一致，保证表单纵向节奏统一。

Data Entry / Radio

Radio 单选框

单选框用于在一组互斥选项中选择一个结果。IQB Agent 平台中常用于任务调度方式、并发策略、错过执行策略等配置项， 需要让当前选择、选项关系和可选范围都保持清晰。

  • 圆点尺寸 14px
  • 选中主色 #22B573
  • 文本字号 12.5px
  • 支持胶囊选项

何时使用

  • 用于一组选项中只能选择一个的场景，例如调度方式、并发策略、错过执行策略。
  • 选项数量建议控制在 2-5 个；选项过多或需要搜索时优先使用 Select。
  • 选项文案应互斥且同一维度，避免把“状态”和“动作”混在一组 radio 中。
  • 需要更强的可扫读性时，可使用胶囊型 radio option 承载短选项。

基础用法

基础单选框

用于普通表单配置，选项之间保持同一语义维度。

垂直排列

长文案选项建议垂直排列，减少阅读跳跃。

组合类型

胶囊型选项

用于周期、筛选维度等短选项，提升横向扫描效率，可与其他控件联动使用。

状态

Default

默认状态使用轻边框圆点和中性文字。

Checked

选中后圆点使用品牌绿填充，并展示浅色 focus ring。

Disabled

禁用态保留可读性，不响应 hover 或切换。

Option Disabled

胶囊型选项也需要提供禁用态，避免不可选项看起来仍可操作。

尺寸

Size

Radio 默认跟随企业表单紧凑节奏，不额外放大圆点；胶囊选项使用 28px 最小高度。

Data Entry / Checkbox

Checkbox 复选框

复选框用于在一组非互斥选项中选择一个或多个结果。IQB Agent 平台中常用于任务能力开关、执行范围、 通知渠道和批量配置项，重点是让已选项、半选关系和禁用范围清晰可见。

  • 方框尺寸 14px
  • 圆角 4px
  • 选中主色 #22B573
  • 支持半选状态

何时使用

  • 用于一组选项中可同时选择多个的场景，例如执行渠道、权限范围、通知方式。
  • 当选项之间互斥时应使用 Radio；当选项数量多且需要搜索时优先使用 Select。
  • 父子层级选择需要提供 indeterminate 半选状态，帮助用户理解局部已选。
  • 批量操作场景中，Checkbox 应与列表、表格或筛选控件保持明确的视觉关联。

基础用法

基础复选框

用于单个布尔配置，可独立切换。

多选组

用于并列选项，选项之间可同时成立。

组合类型

全选与半选

用于父子层级或批量选择场景，父级需要随子项实时展示选中、半选和未选状态。

状态

Default

默认状态使用轻边框和中性文本。

Checked

选中态使用品牌绿填充，并展示白色对勾。

Indeterminate

半选态用于父级选项，表示子项中仅有一部分已选。

Disabled

禁用态保留当前状态，但不响应 hover 或切换。

尺寸

Size

Checkbox 默认跟随企业表单紧凑节奏，控件尺寸为 14px，外层点击热区最小高度为 24px。

  • 只需要小时或分钟粒度时应隐藏无关列，降低选择成本。
  • 涉及范围、秒级时间或关键任务生效时间时，使用确认按钮完成提交。
