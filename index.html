Styles

全局样式 Style

全局样式定义产品界面的基础视觉语言，覆盖颜色、遮罩、字体、投影和主题。 这些规范共同约束组件状态、信息层级、遮挡关系、空间节奏和跨主题的一致体验。

颜色

以当前色板的品牌 500 色为主色基准，按品牌色、中性色、功能色与遮罩值组织颜色规范。 色阶编号从 50 到 900，数值越大颜色越深，500 作为常规态或语义基准色。

  • 品牌色 #00D157
  • 10 阶梯度 50-900
  • 功能色覆盖红 / 黄 / 蓝
  • 适用于组件、状态、遮罩与主题变量

色彩角色

品牌色 用于主按钮、关键操作、选中态、聚焦态和高价值数据。
中性色 用于文本、边框、分割线、背景和弱化信息层级。
功能色 用于错误、警告、提示、链接、信息反馈和状态徽标。

遮罩

遮罩用于压低背景内容的视觉权重，让弹窗、抽屉、确认面板和局部加载状态成为当前操作焦点。 黑色遮罩用于阻断式浮层，白色遮罩用于局部加载；透明度根据阻断程度选择。

弹窗遮罩

用于 Modal、确认弹窗和高阻断任务，背景需要明显退后。

rgba(0, 0, 0, 0.45)

抽屉遮罩

用于 Drawer、侧边配置和局部编辑任务，保留背景上下文。

rgba(0, 0, 0, 0.35)

局部加载遮罩

用于表格、卡片和表单局部加载，弱化内容但不制造强阻断。

rgba(255, 255, 255, 0.72)

使用原则

  • 页面标题与模块标题使用 500 字重，避免通过过粗字重制造层级。
  • 表格、表单和工具栏优先使用 12px-14px 区间，保证信息密度与可读性。
  • 英文、数字和代码值使用等宽字体时，仅限 Token、API、快捷值和可复制内容。

图标 ICON

图标用于补充按钮、输入框、导航和状态表达。图标应保持统一线性风格，默认跟随文字颜色， 通过大小、线宽、拐角和端点约束保证不同组件中的识别一致性。

主题 Theme

当前站点提供 IQ 主题、IQ Buddy 主题和 test 主题 1。主题之间保持组件结构一致， 仅替换品牌色阶、焦点态、局部圆角和字体栈等基础变量，遮罩与中性色保持统一。

IQ 主题

以 iQIYI 标准绿色为品牌主色，适用于默认产品界面。

IQ Buddy 主题

使用更沉稳的绿色色阶，适用于 Buddy 产品语境。

test 主题 1

以蓝色为主色，并使用 2px 控件圆角验证主题差异。

变量范围

Brand --brand-50 到 --brand-900、文本色、边框色和 RGB 值。
Interaction hover、focus、focus ring、输入框聚焦与数字输入框聚焦。
Shape & Font 控件圆角、主题字体栈和组件内需要跟随品牌变化的基础样式。

维护原则

  • 新增主题时先补齐品牌色阶，再校验组件 hover、focus、disabled 和 error 状态。
  • 组件样式优先读取全局变量，避免在组件内部写死可主题化的品牌值。
  • 主题差异只能改变视觉语义，不改变组件结构、交互路径和可访问性表达。
