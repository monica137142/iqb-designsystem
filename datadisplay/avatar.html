Data Display / Avatar

Avatar 头像

Avatar 用于代表用户、团队、Agent 或资源对象，支持图片、图标和字符展示，也可组合徽标、头像组与交互入口表达更完整的身份信息。

  • 默认尺寸 36px
  • Small 30px / Large 44px
  • Icon / 字符 / 图片
  • 支持头像组
  • 支持响应式尺寸

何时使用

  • 用于在列表、卡片、消息、评论和协作成员区域中展示用户、团队、Agent 或资源对象的身份。
  • 身份有稳定图片时优先使用图片头像；没有图片时，使用名称缩写或统一 Icon 作为回退。
  • 同一业务区域应保持头像类型和尺寸一致，避免图片、Icon 与字符头像无规则混排。
  • 需要同时展示多位成员时使用头像组，并通过“+N”收起超出数量，保持界面信息密度稳定。

基础用法

基础头像

Avatar 用于展示对象身份，基础形态包括 Icon、字符和图片。默认使用 36px 圆形头像，可根据数据完整度选择合适的内容类型。

Icon 头像 IQB字符头像 图片头像

头像类型

Icon 头像

Icon 头像可以按身份或业务语义自定义 Icon 颜色和背景颜色。默认使用黑色 Icon 和浅灰背景；Icon 会随头像尺寸自动缩放，以适应头像大小。

默认 Icon 头像 绿色 Icon 头像 蓝色 Icon 头像

字符头像

字符头像默认展示 1 个字符，支持自定义字符数，上限为 5；也支持自适应容纳字符数，字符会根据可用宽度自动调整字号，最多展示 5 个字符。

A默认字符像 IQB蓝色字符头像 Agent橙色字符头像

图片头像

图片使用填充裁切。所有用户头像示例统一使用 DiceBear API，仅作为 Demo 占位内容，不下载到本地；实际项目中可以自定义图片获取来源。

图片头像 A 图片头像 B 图片头像 C

图片加载失败

默认显示 var(--gray-100) 纯色背景，也可以配置自定义色值、备用图片或字符头像。备用图片再次失败时回退到默认纯色。

默认纯色 自定义纯色 自定义图片 自定义字符

头像大小

小、中、大尺寸

通过 size 设置头像大小，支持小 30px、默认 36px、大 44px 三种预设尺寸。

小 30px 中 36px（默认） 大 44px

自定义大小

输入数值可以实时调整头像大小。演示支持 16–300px，超出范围时保留上一次有效尺寸并展示提示。

响应式大小

头像大小根据容器宽高自动调整。拖动容器右下角改变大小，容器宽高范围为 108–300px；默认容器 108px，头像四周保持 36px 间距。

容器 108 × 108px · 头像 36px

头像组

成员组合

使用 Avatar.Group 组合多个头像。成员超过自定义上限时使用“+N”收起剩余成员，N 最大显示为 99+。
