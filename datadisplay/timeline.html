Data Display / Timeline

Timeline 时间轴

Timeline 按时间顺序呈现流程进度、执行记录和事件历史。页面结构参考 Arco Design 的 Timeline 组件， 并沿用 List 页低噪声边框、灰底示例块和紧凑规格表的文档样式。

  • 支持节点状态
  • 支持 label
  • 支持自定义节点
  • 支持横向与交替布局

基础用法

基础 Timeline

Timeline 由多个 Timeline.Item 组成，每个节点包含 label 与 children，用于表达事件顺序。

  1. 2026-08-18
    Create project

    创建项目并同步初始素材。

  2. 2026-08-19
    Review project

    校验内容、价格策略和发布范围。

  3. 2026-08-20
    Publish project

    等待最终确认后发布。

节点状态

状态节点

Timeline Item 支持默认、成功、处理中和错误状态，可通过 dotColor 等属性控制节点色彩。

  1. 默认
    Pending confirmation

    节点处于普通等待状态。

  2. 成功
    Asset checked

    素材清晰度、比例和命名已完成检查。

  3. 处理中
    Pricing running

    价格建议正在生成，预计 2 分钟内完成。

  4. 错误
    Publish failed

    部分渠道缺少必填字段，需要补齐后重试。

自定义节点

自定义 dot

dot 可以替换为图标、自定义元素或状态标识，用于突出特殊节点。

  1. 09:12
    素材已接入

    图片、标题、规格参数进入审核队列。

  2. 09:20
    Agent 处理中

    识别重复关键词并合并商品描述。

  3. 09:35
    需要人工确认

    检测到敏感词，需要运营确认替代文案。

交替排列

alternate 模式

交替排列让时间轴内容在轴线两侧展示，也可控制内容整体位于 left、right 或 alternate。

  1. 2026-08-18
    Create project

    初始化项目并写入任务配置。

  2. 2026-08-19
    Review project

    设计、内容和数据规则进入复核。

  3. 2026-08-20
    Publish project

    按计划推送到生产环境。

  4. 2026-08-21
    Observe metrics

    持续观察曝光、点击与转化数据。

横向时间轴

Horizontal Timeline

设置横向时间轴时，内容可位于 top、bottom 或 alternate；窄屏下横向滚动查看。

  1. 2026-08-18 Create project
  2. 2026-08-19 Review project
  3. 2026-08-20 Publish project
  4. 2026-08-21 Observe metrics

API

属性 说明 类型 默认值
mode 时间轴内容排列方式，可控制整体位于左、右或交替排列。 'left' | 'right' | 'alternate' 'right'
direction 时间轴方向，支持垂直和横向展示。 'vertical' | 'horizontal' 'vertical'
labelPosition 横向时间轴内容位置，可位于顶部、底部或交替展示。 'top' | 'bottom' | 'alternate' 'bottom'
pending 展示最后一个幽灵节点，用于表示仍有任务等待发生。 boolean | ReactNode false
reverse 倒序排列节点，适合最新事件优先展示的日志流。 boolean false
dotSize 默认节点直径；当前规范统一为 6px 实色圆点。 number | string var(--timeline-dot-size)
lineGap 节点与连接线之间的间距，竖向、自定义节点和横向时间轴保持一致。 number | string var(--timeline-line-gap)
Timeline.Item 属性 说明 类型 默认值
label 节点辅助信息，通常展示时间、日期或阶段说明。 ReactNode -
dot 自定义节点内容，可传入图标、自定义元素或状态标识。当前示例使用 22px 浅色底节点和 14px 线性 SVG 图标。 ReactNode -
dotColor 节点颜色，用于表达成功、处理中、错误或自定义状态；优先传入状态语义色 Token。 string var(--timeline-dot-color)
lineType 节点连线类型。 'solid' | 'dashed' | 'dotted' 'solid'
className 节点自定义类名；自定义 dot 节点可用于控制连接线避让较大节点。 string -

设计 Token

Token 说明 默认值
--timeline-axis-color 时间轴连接线颜色。 var(--color-border-subtle)
--timeline-frame-border-color 时间轴示例框体与布局卡片的描边语义色。 var(--color-border-subtle)
--timeline-dot-color 无状态节点的默认语义色。 var(--color-border-default)
--timeline-dot-border-radius 时间轴节点圆角。 var(--radius-full)
--timeline-dot-size 默认节点直径。 6px
--timeline-dot-radius 默认节点半径，用于横向时间轴计算连接线避让距离。 3px
--timeline-line-gap 节点与连接线之间的间距。 8px
--timeline-custom-dot-size 自定义 dot 外层节点尺寸。 22px
--timeline-custom-icon-size 自定义 dot 内部线性 SVG 图标尺寸。 14px
--timeline-label-width 垂直时间轴 label 区域宽度。 104px
--timeline-item-gap label、dot 与内容之间的水平间距。 12px
--timeline-content-padding 垂直时间轴单个节点的内容区间距。 0 0 28px
--timeline-layout-item-height left / right 紧凑示例中每个节点的统一节奏高度。 54px
--timeline-card-radius 示例承载容器圆角，保持与 List 页一致。 var(--radius-large)
--timeline-horizontal-height 横向时间轴示例的最小高度。 190px
--timeline-label-font-* 时间与辅助标签文字样式。 var(--font-style-caption-*)
--timeline-title-font-* 节点标题文字样式。 var(--font-style-body-medium-*)
--timeline-description-font-* 节点描述文字样式。 var(--font-style-caption-*)
