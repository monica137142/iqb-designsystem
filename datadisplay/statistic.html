Data Display / Statistic

Statistic 数值显示

Statistic 用于展示一组清晰、可比较的数值信息。参考 Arco Statistic 的内容结构，组件由 title、value、prefix、suffix 和 Countdown 等能力组成，适合仪表盘指标、任务结果、余额用量和实时倒计时。

  • Title / Value
  • Prefix / Suffix
  • 数值动画
  • Countdown
  • 支持前后缀

基础用法

基础 Statistic

基础用法由 Title 和 Value 组成，Title 表示统计指标名称，Value 表示统计数值。

Title: 统计指标名称 1,260
Value: 统计数值 12,486

前缀与后缀

Prefix / Suffix

支持在数值前后增加内容，Prefix 可展示货币符号、图标，Suffix 可展示百分比、单位或趋势状态。

Prefix: 货币符号 $ 86,240
Suffix: 百分比 7.32 %
Suffix: 单位 128 GB
Suffix: 上升趋势 18.6 ↑ 12.4%
Suffix: 下降趋势 2.8 ↓ 0.6%
Prefix: 收藏数图标 9,840

数值动画

动态变化到目标值

数值可从初始值平滑变化到目标值，用于首次展示或数据更新。点击每个指标下方按钮后分别重新播放动画。

从 0 动画到 348 0
从 0.0% 动画到 27.6% 0.0 %

倒计时

Countdown

Countdown 用于展示剩余时间，常见格式包括时 / 分 / 秒、时 / 分 / 毫秒、天 / 时 / 分 / 秒，并支持倒计时结束事件。

从 3 小时 30 分开始倒计时 03:30:00
HH:mm:ss.SSS 00:03:05.000
1 天 23 时 47 分 38 秒 1 天 23 时 47 分 38 秒
倒计时进行中 00:00:06

API

属性 说明 类型 默认值
title 统计标题或说明文案，当前案例中承载原 title 与 help 信息。 ReactNode -
value 统计数值。 number | string -
prefix 数值前缀，例如货币符号或收藏图标。 ReactNode -
suffix 数值后缀，例如百分比、单位或上升 / 下降趋势。 ReactNode -
trend 趋势状态，用于区分上升、下降后缀的语义色。 "up" | "down" -
iconPrefix 图标前缀，用于收藏数等需要符号强化的数值。 ReactNode -
precision 数值精度，控制小数位展示。 number -
groupSeparator 千分位分隔符。 string ,
animation 是否开启数值动画，可由外部按钮触发播放。 boolean false
start 动画初始值。 number 0
countdown 启用倒计时类型展示，倒计时标题可承载格式或状态说明。 boolean false
format 倒计时格式，如 HH:mm:ss、HH:mm:ss.SSS、D 天 H 时 m 分 s 秒。 string HH:mm:ss
onFinish 倒计时结束时触发，可更新标题状态。 () => void -
