Data Display / Table

Table 表格

表格用于管理自动化任务、执行记录、权限申请和任务配置等结构化对象。规范参考 业务工作台 自动化 tab 中的分组表格、轻量表头、任务行、开关状态和执行记录入口，强调高密度扫描、稳定操作列和低噪声状态反馈。

  • 默认行高 44px
  • 表头高度 44px
  • 卡片圆角 8px
  • 支持分组、启停和执行记录联动

何时使用

  • 需要横向比较任务名称、调度规则、下次执行、最近结果、创建人和任务状态时使用表格。
  • 需要在任务列表中直接完成启停、编辑、重试、查看执行记录等操作时使用自动化表格。
  • 当对象按流程或 Agent 分组管理时，使用「分组标题 + 表格卡片」结构，避免把所有任务混在一个长表中。
  • 表格上方只放自动化范围 tab 和主操作；搜索、筛选和导出等低频动作进入工具栏或更多入口。

尺寸

尺寸规格

自动化任务表格按 Compact、Default、Relaxed 三档定义行高；Default 为默认尺寸，Compact 用于高密度扫描，Relaxed 用于含补充说明或参数标签的列表。

尺寸 行高 使用场景
Compact 36px 右侧执行记录、短列表预览、只读日志。
Default 44px 自动化任务、定时任务、配置审核主列表。
Relaxed 56px 带多行参数、失败原因或执行摘要的任务列表。

API

属性 说明 类型 默认值
columns 列定义，包含标题、数据字段、宽度、固定方式、排序筛选能力和渲染函数。 TableColumn[] []
dataSource 表格数据源，每行应提供稳定唯一的 rowKey。 Record[] []
rowSelection 控制单选、多选、全选、不可选项和批量操作状态；多选框复用 Checkbox 的 14px 圆角方形规范，批量重试使用 Primary Button。 object | false false
sorter 表头排序配置，使用 16px 实色圆角三角图标和 4px 箭头间距，支持正序、倒序、取消排序循环切换。 object | false false
filters 表头筛选配置，浮层复用 Dropdown 规范，支持圆角方形复选或单选菜单；确认后更新列表。 object {}
searchable 是否在指定表头展示 Search 语义图标入口；24px 无描边 Icon Button 的 hover 背景比表头深一级，点击后以浮层形式打开搜索输入框，非实时过滤。 boolean | object false
expandable 展开行配置，用于在当前行下方展示参数、对象和记录摘要；内容起点与任务名称列左对齐。 object | false false
fixedColumns 固定列配置，支持首列和末列固定，中间列横向滚动；固定列边缘显示微弱纵向投影。 { left?: number; right?: number } -
editable 可编辑单元格配置；文本输入激活时使用 shadow-focus。调度规则默认左对齐显示 Label，第一次点击切换为 Select Trigger，第二次点击展开选择浮层。 object | false false
draggable 是否开启拖拽排序；左侧锚点使用 6 个半径 2px 的 Grip 圆点和 24px 无描边 Icon Button 热区，排序完成后更新数据顺序。 boolean false
activeRowKey 当前详情联动或新建行；使用 20% 不透明度品牌色背景，不增加左侧色条标记。 string | number -
pagination 分页配置，包含当前页、每页数量、总数和每页数量选项。 object | false { pageSize: 5 }
size 表格尺寸，影响表头、数据行高和单元格内边距。 compact | default | relaxed default
actionButtonSize 表格内文字操作按钮尺寸；图标型表头操作保持各自的紧凑尺寸。 small | default | large default
loading 加载状态；开启时保留表头和列宽，行区域复用 Skeleton 骨架屏的扫光动效。 boolean false
empty 空状态配置；普通空列表、搜索空结果和筛选空结果使用统一 Empty 样式。 object { title, description }
onRowOpen 点击行或「执行记录」按钮时触发，用于打开执行记录抽屉。 (record) => void -
onToggle 点击 Switch default 开关时触发，用于暂停或开启任务。 (record, enabled) => void -
onAdd 点击表格右上角 primary「添加」按钮时触发，用于新增一行。 () => void -
onDelete 点击操作列「删除」按钮时触发，用于删除当前行。 (record) => void -
onDragSort 拖拽排序完成后触发，返回新的数据顺序。 (records) => void -
