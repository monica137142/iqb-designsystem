Data Display / List

List 列表

List 用于承载连续对象、摘要信息、行内操作、网格列表和滚动加载场景。 规范保留低噪声边框、8px 卡片圆角，并将 small / default / large 行高统一为 36 / 44 / 72px。

  • 行高 36 / 44 / 72px
  • 支持 header
  • 支持 Meta / actions
  • 支持 grid / scroll loading

何时使用

  • 同类对象按纵向流排列，并以标题、描述、头像或行内操作为主要信息时使用 List。
  • 纯文本单行列表使用 default 44px；含头像或标题加描述的两行列表使用 large 72px。
  • 需要分组语义时使用 header；需要持续追加数据时使用滚动触底加载。
  • 需要多字段横向比较、批量选择、排序筛选时切换为 Table；少量对象摘要可使用 Grid Card。

API

属性 说明 类型 默认值
dataSource 列表数据源。 T[] []
render 自定义渲染每一项内容。 (item, index) => ReactNode -
header 列表头部内容，用于集合名称、范围说明或轻量统计。 ReactNode -
size 列表尺寸。 "small" | "default" | "large" "default"
grid 网格列表配置，可渲染三行列表卡片或头像摘要卡片。 GridProps -
actions List.Item 操作集合。 ReactNode[] -
scrollLoading 滚动加载状态，触底加载时展示 loading 区域。 boolean false
onReachBottom 滚动到底部时触发，用于请求并追加下一组数据。 () => void -
onListScroll 自定义列表滚动监听；使用后可接管默认触底判断。 (event) => void -
