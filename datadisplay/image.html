Data Display / Image

Image 图片

图片用于承载商品、内容、人物与场景等视觉信息，提供统一的填充、圆角、加载、失败和悬停反馈规范。

  • 默认 Fill
  • 默认圆角 8px
  • 支持懒加载
  • 支持失败回退

何时使用

  • 需要在卡片、列表、详情或媒体浏览场景中稳定展示图片资源时使用。
  • 图片尺寸与容器比例不一致时，应明确选择 Fill 或 Fit，并保持同一业务区域策略一致。
  • 图片是内容主体时提供加载、失败与重试反馈；纯装饰图片不应抢占阅读焦点，并使用空 alt。
  • 头像等具有明确形状语义的内容可使用纯圆；普通内容图片默认使用 8px 圆角。

基础用法

为图片提供明确的容器尺寸和替代文本。组件默认采用 Fill 填充容器，并使用 8px 圆角。

填充方式

Fill（填充）为默认模式，图片等比放大并裁切溢出内容，横向原图的左右区域会被裁切并保持主体居中；Fit（适合）完整展示图片，并在比例不一致时保留未填充区域。

图片为 Fit 时未填充区域

Fit 模式可使用默认黑色、指定颜色、图片主色或当前图片的模糊副本填充留白。以下四组均使用相同四张图片，比例依次为 16:9、16:9、9:16、9:16，便于直接比较不同背景策略。

圆角

内容图片默认圆角为 8px，也支持直角和自定义圆角；头像、品牌徽记等等宽高且具有圆形语义的内容可使用纯圆。

图片加载

纯色占位

图片未加载完成时使用纯色占位，默认使用浅灰色并支持自定义颜色。适合小尺寸图片、圆形头像，或图片尺寸小于 Loading 图标的场景。

Loading 图标占位

中等及以上尺寸图片可在浅灰底上展示 Loading 图标，明确告知用户资源仍在请求中。

流动渐变

使用一种主色（默认为品牌色）与两种邻近色形成缓慢流动的渐变，避免单色过于单调，常用于 AI Chat 图片生成场景。默认演示持续流动；重新演示会同时控制三张生成图片。

图片懒加载

图片进入可视区域时先展示默认浅灰纯色占位，资源可用后由模糊图平滑过渡为清晰图。重新演示会同时控制三张图片。

图片加载失败

加载失败前保持 Loading 状态；失败后在浅灰底上展示与 Loading 图标同尺寸的浅色裂图图标，并允许用户重新请求。

图片 Hover 及查看

鼠标悬停或键盘聚焦时覆盖黑色遮罩，默认不透明度为 75%，并居中展示“查看”小字。点击图片后进入全屏查看，使用 75% 黑色蒙层聚焦内容，预览图保持默认容器比例，最大宽度和高度均不超过视口的 70%。
