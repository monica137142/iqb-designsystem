Data Display / Tag

Tag 标签

Tag 用于标记状态、属性、分类和轻量筛选条件。组件保持信息展示优先，只有在开启 closable 或 checkable 后才承担删除或选择交互。

  • 默认 Neutral 基底
  • 支持 soft / solid / outline
  • 支持 closable
  • 支持 checkable

何时使用

  • 用于标记对象的状态、分类、属性或轻量级业务语义，帮助用户在列表、表格和详情中快速扫描。
  • 默认 Tag 只做信息展示；需要删除已选项时使用 closable，需要切换筛选或兴趣项时使用 checkable。
  • 同一组标签保持稳定的颜色映射，避免在同一区域让同一颜色表达多种含义。
  • 标签文案应短而明确；需要承载主要操作、复杂选择或批量编辑时，应切换为 Button、Checkbox、Select 等组件。

标签尺寸

提供 small（20px）、default（24px）、medium（28px）、large（32px）四种高度，覆盖表格内紧凑信息、普通状态标记和更强调的业务标签。

支持动态新增 Tag。典型流程：点击“添加标签”，输入内容，创建新的 Tag；同时支持删除已有 Tag。
