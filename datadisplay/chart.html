Data Display / Chart

Chart 图表

Chart 用于呈现趋势、对比和占比。页面底层统一使用 VChart 渲染，视觉样式继承当前 Design Token，便于设计验收和研发复用。

  • VChart renderer
  • 100% responsive
  • Token based theme
  • Unified tooltip

何时使用

  • Basic Charts

    折线、柱状、面积、饼图和环图均为真实 VChart Demo。

  • Theme Mapping

    分类色、字体、边框、背景和圆角读取 design.md 中的全局 Token。

  • Implementation

    页面内仅保留简单公共配置、Demo 数据和 VChart 初始化逻辑。

Basic Charts

Line Chart / Single Line

用于展示连续时间维度下的单一指标变化趋势。

Loading chart
Code 
const spec = {
  ...commonChartConfig({ ruler: true }),
  type: 'line',
  data: [{ id: 'lineSingle', values: lineSingleData }],
  xField: 'date',
  yField: 'value',
  line: { style: { lineWidth: 2 } },
  point: commonPointConfig()
};

Line Chart / Multi Line

用于比较多个系列在同一时间维度下的变化。

Loading chart
Code 
const spec = {
  ...commonChartConfig({ legend: true, ruler: true }),
  type: 'line',
  data: [{ id: 'lineMulti', values: lineMultiData }],
  xField: 'date',
  yField: 'value',
  seriesField: 'series',
  point: commonPointConfig()
};

Area Chart

用于强调趋势走势，同时以低透明度区域辅助阅读。

Loading chart
Code 
const spec = {
  ...commonChartConfig({ ruler: true }),
  type: 'area',
  data: [{ id: 'area', values: areaData }],
  xField: 'date',
  yField: 'value',
  area: { style: { fillOpacity: 0.16 } },
  point: commonPointConfig()
};

Area Chart / Multi Line

用于比较多个趋势系列，并保留面积层次辅助判断波动。

Loading chart
Code 
const spec = {
  ...commonChartConfig({ legend: true, ruler: true }),
  type: 'area',
  data: [{ id: 'areaMulti', values: areaMultiData }],
  xField: 'date',
  yField: 'value',
  seriesField: 'series',
  stack: false,
  area: { style: { fillOpacity: 0.12 } },
  point: commonPointConfig()
};

Bar Chart / Basic Bar

用于展示离散分类之间的数值对比。

Loading chart
Code 
const spec = {
  ...commonChartConfig(),
  type: 'bar',
  data: [{ id: 'barBasic', values: barBasicData }],
  xField: 'name',
  yField: 'value',
  bar: { style: { cornerRadius: 0 } },
  label: commonLabelConfig()
};

Pie Chart

用于展示 5 到 6 个以内分类的占比关系。

Loading chart
Code 
const spec = {
  ...commonPolarChartConfig({ legend: true }),
  type: 'pie',
  data: [{ id: 'pie', values: pieData }],
  categoryField: 'category',
  valueField: 'value',
  outerRadius: 0.82
};

Donut Chart

用于展示占比结构，中心保留总量或核心数值。

Loading chart
Code 
const spec = {
  ...commonPolarChartConfig({ legend: true }),
  type: 'pie',
  data: [{ id: 'donut', values: donutData }],
  categoryField: 'category',
  valueField: 'value',
  innerRadius: 0.62,
  outerRadius: 0.86,
  indicator: { visible: true, title: { text: 'Total' } }
};

Chart Elements

Color

数据系列直接引用 color-category-* 分类色，最多支持 10 个分类。

Axis & Grid

坐标轴文字使用 Secondary Text，轴线和网格线使用 Subtle Border，整体弱于数据图形。

Legend

图例使用 Caption 字号和 Secondary Text，未选中态降低透明度，Marker 跟随系列色。

API

配置 说明 默认
type VChart 图表类型，例如 line、bar、area、pie。 -
data VChart 数据源配置，Demo 统一使用扁平数据对象。 []
xField / yField 笛卡尔坐标系的数据映射字段。 -
categoryField / valueField 饼图和环图的分类和值映射字段。 -
seriesField 多系列图表的颜色映射字段，并用于图例展示。 -
commonChartConfig() 笛卡尔图表公共配置，统一 10 色色板、坐标轴、网格、Legend、Tooltip 与 Crosshair。 Token based
commonPolarChartConfig() 饼图与环图公共配置，复用 10 色色板、Legend、Tooltip 和语义背景。 Token based
commonLegendConfig() 底部 Legend 配置；selectedHover 与 unSelectedHover 使用语义文字、Hover 背景及 6px 语义圆角。 visible: false
commonTooltipConfig() Tooltip 面板、文字与阴影均读取语义 Token，并随明暗模式切换。 Inverse surface
commonCrosshairConfig() 折线图提供左侧数值 Tooltip；柱状图光标区域使用语义 Hover 背景。 ruler: false
commonLabelConfig() Basic Bar 顶部数值标签，文字使用 Tertiary，2px 描边跟随容器背景语义色。 position: top
