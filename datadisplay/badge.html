Data Display / Badge

Badge 徽标

Badge 徽标用于在元素右上角或文本旁展示数量、提醒与状态，以轻量方式突出用户需要关注的信息。

  • 数字 / 小红点 / 状态
  • 默认高度 20px
  • 小号高度 16px
  • 数字默认封顶 99+
  • 支持自定义颜色

何时使用

  • 在导航、按钮、头像或文本入口旁提示未读数量、待处理任务或新内容。
  • 只需表达“有更新”而无需显示数量时，使用小红点徽标。
  • 说明对象当前状态时，使用带名称的状态徽标，不要仅依赖颜色传达含义。
  • 徽标应保持简短，避免承载复杂文案或替代重要的页面反馈。

基础用法

数字提醒

将徽标附着在需要提示的元素右上角。默认展示数字，并以醒目的红色强调待处理信息。

3圆形提醒8 条消息

字符徽标

字段配置

字段支持数字和自定义字符两种类型，默认为数字。99 以内正常显示，超过 99 默认显示 99+，也可以自定义封顶数字；自定义字符适合 NEW、HOT 等短字段。

8数字9999 以内99+默认封顶 9950+自定义封顶 50NEW自定义字符 NEWHOT自定义字符 HOT

颜色配置

默认使用红色底和白色文字，也可按业务语义自定义背景色。

8默认红色徽标8蓝色徽标8绿色徽标8紫色徽标

尺寸配置

默认高度为 20px；信息密度较高的紧凑场景可使用 16px 小号徽标。

8默认 20px8小号 16px

小红点徽标

颜色与尺寸配置

默认颜色为红色，支持自定义颜色。默认尺寸为 6px，支持在 6–10px 范围内自定义大小。

状态徽标

用法描述

设置 status 可得到 default、success、warning 和 error 状态；状态点默认尺寸为 6px，支持在 6–10px 范围内自定义大小，也支持自定义状态名称与颜色。
